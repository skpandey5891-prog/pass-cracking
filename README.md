# Dropzone — Community Tournament Hub

A responsive, fan-made Free Fire community tournament dashboard with sample fixtures, standings, and a player spotlight. Team, player, schedule, and results data are fictional placeholders for the demo.

This project is unofficial and is not affiliated with or endorsed by Garena. It does not connect to game services, collect credentials, or provide gameplay modifications.

## Run locally

No dependencies or build step are required. Open `index.html` directly in a browser, or run a local static server from the repository root:

```sh
python -m http.server 8000
```

Then visit <http://localhost:8000>.

## Features

- **Tournament Fixtures**: View upcoming matches and completed results across different maps
- **Leaderboard**: See top squads ranked by points with trend indicators
- **Player Spotlight**: Browse community players with their K/D ratios and team affiliations
- **Responsive Design**: Works on desktop, tablet, and mobile devices
- **Accessible UI**: Built with semantic HTML and ARIA labels

## Data

All tournament data (teams, players, scores, schedules) is fictional and created for demonstration purposes only.
